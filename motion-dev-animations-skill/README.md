# motion-dev-animations-skill

Single skill from <https://github.com/199-biotechnologies/motion-dev-animations-skill>
(see LICENSE). Generates production TypeScript/JSX animations with **Motion.dev** (the
Framer Motion successor) for React, Next.js, Svelte, and Astro — entrance/gesture/scroll/
layout animations with spring physics, `prefers-reduced-motion` accessibility, and a
≥60fps performance check built into the workflow. Not for CSS-only transitions, Vue
(different package), or complex SVG/Canvas work (GSAP fits those better).

Entry point: [`SKILL.md`](SKILL.md). Supporting: `examples/`, `reference/`, `schema/`,
`scripts/`, `templates/`. Dropped repo-development files (`ACTIVATION_TEST.md`,
`DEPLOYMENT_STATUS.md`, `RESEARCH_SYNTHESIS.md`, `VALIDATION_V3.md`, `SKILL.md.backup`,
`CONTRIBUTING.md`).
