# security-audit-skill — Skill

From <https://github.com/cloudflare/security-audit-skill> (Cloudflare, official).
**Type: Skill.**

Multi-phase security audit workflow for codebases, APIs, services, CLI tools,
libraries, daemons — produces independently-verified, machine-readable findings.
Defensive, source-first: a finding needs a concrete affected principal/resource and a
real trust-boundary violation, safe reproduction, priority, and the smallest effective
fix, not just a pattern match.
