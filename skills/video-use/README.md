# video-use — Skill

From <https://github.com/browser-use/video-use> (MIT, browser-use org). **Type: Skill**
(the whole repo is the skill payload — `helpers/` and `static/` are code the skill
itself calls, per `SKILL.md`: "Helpers... live alongside this SKILL.md").

Edit any video by conversation: transcribe, cut, color grade, generate overlay
animations, burn subtitles — talking heads, montages, tutorials, travel, interviews.
Works from a packed phrase-level transcript rather than fixed presets/menus. Ships a
sub-skill `skills/manim-video/` for Manim-based overlay animation.

Dropped: `tests/`, `.env.example`, `pyproject.toml` scaffolding, `poster.html` (repo
demo page).
