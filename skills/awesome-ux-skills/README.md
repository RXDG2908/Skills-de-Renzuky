# awesome-ux-skills

23 UX skills from <https://github.com/tommyjepsen/awesome-ux-skills> (no upstream LICENSE file — flag before redistributing). Flat format: each top-level `<name>.md` file IS the skill (no SKILL.md subfolder). Covers heuristics review, personas, journey/storyboard mapping, double-diamond process, accessibility, persuasive UX, AI-interface patterns (ai-governors/identifiers/inputs/trust-builders/tuners/wayfinders), and Dieter Rams's principles. `install.sh`/`uninstall.sh` (upstream) copy these into `~/.claude/skills/<name>/`.
