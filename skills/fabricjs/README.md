# fabricjs — Skill (repo-maintainer only)

From <https://github.com/fabricjs/fabric.js> (MIT) — the JS canvas library itself
(261MB: source, build, tests, docs) was not brought in, only its one bundled skill.

**`fabricjs-open-pr`** — narrow, repo-specific: generates a conventional-commit PR
title/description, updates `CHANGELOG.md` under `[next]`, predicts/reconciles the PR
number. Only useful when actually opening a PR against `fabricjs/fabric.js` itself —
not a general "build with Fabric.js" skill.
