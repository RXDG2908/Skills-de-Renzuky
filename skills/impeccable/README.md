# impeccable

Single skill from <https://github.com/pbakaus/impeccable> (Apache-2.0). Design-craft reviewer/builder for UI code — same territory as taste-skill/craft. The upstream repo vendors ~20 identical copies of this one skill for different coding-agent tools (.claude, .cursor, .gemini, ...); kept only the .claude copy (fullest: includes reference/ + scripts/). See NOTICE.md: platform reference files are adapted from ehmo/platform-design-skills (MIT) with attribution.

- **impeccable** — Use when the user wants to design, redesign, shape, critique, audit, polish, clarify, distill, harden, optimize, adapt, animate, colorize, extract, or otherwise improve a frontend interface. Covers websites, landing pages, dashboards, product UI, app shells, components, forms, settings, onboarding,…
