# Not a skills collection

`claude-quickstarts` (from https://github.com/anthropics/claude-quickstarts) is Anthropic's
example-app repo, kept here for reference only — it contains **no design skills**.

Useful as reference patterns for:
- `agents/` — Claude Agent SDK usage
- `managed-agents/` — server-hosted agents
- `computer-use-demo/`, `browser-use-demo/` — computer/browser use loops
- `customer-support-agent/`, `financial-data-analyst/` — full app examples

`.git` was removed; re-clone upstream for updates.
